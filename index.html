Kebijakan Privasi — Scan PDF Tanpa Watermark

Terakhir diperbarui: 7 November 2026. Pengembang: ALQ Studio. Kontak: alqappsmetro@gmail.com

Dokumen Anda tidak pernah meninggalkan perangkat Anda

Aplikasi ini memproses semua pemindaian di perangkat Anda sendiri. Foto dokumen, hasil pindaian, teks hasil OCR, dan berkas PDF/JPG yang Anda buat hanya tersimpan di penyimpanan internal perangkat Anda. Kami tidak memiliki server untuk menerima dokumen pengguna, tidak menyediakan akun, dan tidak pernah mengunggah, menerima, atau menjual dokumen Anda kepada siapa pun.

Pemrosesan di perangkat

Deteksi tepi, koreksi perspektif, filter gambar, dan pengenalan teks (OCR Bahasa Indonesia dan Inggris) dijalankan di perangkat dengan teknologi pembelajaran mesin di perangkat (Google ML Kit). Berkas yang Anda bagikan lewat fitur ekspor/bagikan sepenuhnya berada di bawah kendali Anda — aplikasi hanya meneruskannya ke aplikasi tujuan yang Anda pilih sendiri (misalnya WhatsApp, email, atau Drive Anda).

Tanpa akun

Aplikasi tidak meminta pendaftaran, login, alamat email, atau data identitas apa pun untuk digunakan.

Iklan (Google AdMob)

Aplikasi menampilkan iklan melalui Google AdMob — hanya berupa banner kecil di bagian bawah layar perpustakaan; tidak ada iklan di alur memindai, mengedit, dan mengekspor. Untuk menayangkan dan mengukur iklan, SDK Google Mobile Ads dapat mengumpulkan data berikut sesuai kebijakan Google (policies.google.com/privacy): ID perangkat/ID iklan, interaksi aplikasi, data diagnostik, dan lokasi perkiraan. Aplikasi tidak mengirimkan isi dokumen, hasil pindaian, atau teks OCR Anda ke layanan iklan.

Izin aplikasi

Aplikasi memakai izin kamera (untuk memindai dokumen), internet, dan status jaringan (untuk iklan). Aplikasi tidak meminta akses ke kontak, lokasi presisi, mikrofon, atau penyimpanan bersama perangkat Anda.

Penghapusan data

Anda dapat menghapus dokumen satu per satu atau seluruhnya dari dalam aplikasi kapan saja. Menghapus (uninstall) aplikasi juga menghapus seluruh dokumen dan datanya dari perangkat. Karena tidak ada data yang tersimpan di server kami, tidak ada data di pihak kami yang perlu diminta untuk dihapus.

Anak-anak

Aplikasi ini adalah alat produktivitas untuk pengguna umum dan tidak diarahkan khusus kepada anak-anak.
